# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-04-03

### Added

- Initial release of i9 Schedule integration
- Multi-child support with automatic entity creation
- Game information sensors (time, location, opponent, jersey color, etc.)
- Binary sensors for game today/this week
- Configurable polling interval
- Services for retrieving game details and filtering schedules
- Force update service for manual API calls
- Setup flow with username/password authentication
- Example automations for notifications and reminders
- Full localization support (English)
